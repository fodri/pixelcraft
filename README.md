# PixelCRAFT

Felülnézetes túlélő-crafting játék, co-op móddal.

## Telepítés
- **Windows:** töltsd le a `PixelCRAFT-Setup.exe`-t a [Releases](../../releases/latest) oldalról, és futtasd.
- **Linux:** töltsd le a `PixelCRAFT-Linux.tar.gz`-t, csomagold ki, majd futtasd: `./PixelCRAFT-Linux/install.sh`

A kliens minden indításkor megnézi, van-e új verzió, és magától letölti. Ehhez a mappához ne nyúlj: az `index.html` és a `version.json` a frissítés forrása.
